# 🏠 HomeFix

HomeFix is a full-stack home services marketplace that connects customers with local service providers. Customers can browse services, book providers, submit custom service requests, and manage their bookings, while providers can manage their services, bookings, earnings, reviews, and customer requests.

## 🚀 Features

### 👤 Customer
- User registration and login
- Browse available home services
- View service details
- Book services
- Submit custom service requests
- Track and manage bookings
- View notifications
- Submit reviews and ratings
- Manage customer profile

### 🛠️ Service Provider
- Provider registration and login
- Provider dashboard
- Add and manage services
- Manage customer bookings
- Manage custom service requests
- Track earnings
- Manage provider profile
- View customer reviews
- Provider notifications
